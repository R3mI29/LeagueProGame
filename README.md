**U have to start the server for using this website.**  
- Open a terminal in the "LeagueProGame" directory, and type " node server/index.js "  
- Open another terminal in the same directory, and type " npm run dev -- --host  " Now u should have a network address in the second terminal, use it for the host and for all players.
